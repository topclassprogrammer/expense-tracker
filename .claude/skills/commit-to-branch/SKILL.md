# Коммит в ветку

## Формат сообщения

Conventional Commits: `<type>: <краткое описание>` (при необходимости `<type>(scope): ...`).

- Заголовок — на английском, в императиве, без точки в конце.
- Типы: `feat`, `fix`, `refactor`, `chore`, `docs`, `test`.
- Тело коммита (если есть) объясняет **почему**, а не пересказывает диф.

## Когда коммитить

Коммитить только по явной просьбе пользователя — не создавать коммиты проактивно после каждой правки.
